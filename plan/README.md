# Home Plans

Future plans for the home, one folder per category.

| Category | Covers |
|---|---|
| [Garden](garden/README.md) | Vegetables, herbs, fruit trees, beds, soil, compost and the planting calendar. |
| [Livestock](livestock/README.md) | Chickens, other animals, housing and fencing, feed, care routines and costs. |
| [Water](water/README.md) | Rain catchment, irrigation, storage tanks, filtration and water for animals and the garden. |
| [Energy](energy/README.md) | Solar, backup power, heating and cooling, insulation and efficiency upgrades. |
| [Food Storage](food-storage/README.md) | Pantry, canning, freezing, drying, root cellar and preserving the harvest. |
| [Improvements](improvements/README.md) | Renovations, builds and upgrades to the house, yard and outbuildings. |
| [Maintenance](maintenance/README.md) | Seasonal chores, repairs, appliance care and recurring upkeep. |
| [Budget](budget/README.md) | Cost estimates, priorities and what to buy or build first across all plans. |
